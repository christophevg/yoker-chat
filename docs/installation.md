# Installation

## Requirements

- Python 3.10 or higher
- uv package manager

## Install via uv

```bash
uv tool install yoker-chat
```

## Install via pip

```bash
pip install yoker-chat
```

## Development Installation

```bash
git clone https://github.com/christophevg/yoker-chat.git
cd yoker-chat
uv sync
```

## Verify Installation

```bash
yoker-chat --help
```
